# Machine Failure Prediction — Streamlit demo

## What this is
A simple interface around the `model.pkl` artifact generated by the supplied notebook.

**Important limitation:** the notebook uses `sklearn.datasets.make_classification()` to generate a synthetic dataset. Its 20 columns are generic features, not real machine sensor readings. Treat this as a learning/demo project, not a validated maintenance model.

## Folder contents
- `app.py` — Streamlit user interface and prediction code
- `requirements.txt` — Python packages
- `model.pkl` — the model artifact supplied with the notebook

## Run on Windows
Open Command Prompt or PowerShell in this folder, then run:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Streamlit should open a local browser tab. If it does not, use the local URL printed in the terminal.

## If loading fails
The notebook artifact stores a dictionary with the trained estimator under the key `"model"`. The app supports that structure and also supports an estimator saved directly. If scikit-learn reports a version warning/error, install a compatible version based on the environment that created the pickle. The notebook imports scikit-learn 1.6.1 in the artifact metadata, so start by trying `scikit-learn==1.6.1` if necessary.

## Security
Only load `.pkl` / joblib files from a trusted source. Deserializing these files can execute code. This app expects the artifact that you received with the notebook.

## How to explain it in a hackathon
1. The notebook creates a synthetic, imbalanced binary classification dataset.
2. It uses a stratified train/test split.
3. It evaluates a majority-class `DummyClassifier` baseline.
4. It trains Logistic Regression and prints a classification report.
5. It saves `{"model": model2}` to `model.pkl`.
6. The Streamlit app collects 20 numeric values, passes them to the saved model, and displays the predicted class and probability.
